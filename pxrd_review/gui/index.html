    Select a manuscript.

    Its in-text citations are checked against its own reference list — cited but not listed, listed but not cited, year/spelling mismatches, and form (et al., year letters, initials). Tick the companion files (a separate table docx) whose citations count. Run writes an annotated copy to review_out/<name>_refs.docx, skipping what you dismissed; the source is never edited. Equivalent command: pxrd refs "paper.docx" --with "Table 1.docx".
